# ARSpace

ARSpace is an Android-based Augmented Reality workplace visualization application that enables commercial real estate clients to preview and customize office layouts inside bare-shell office spaces before construction.

## Tech Stack

- Unity 6.5
- AR Foundation
- Google ARCore
- C#

## Features (Planned)

- Plane Detection
- Furniture Placement
- Object Anchoring
- Move / Rotate / Scale
- Layout Templates
- Space Utilization Analysis
- Local Layout Save & Load

## Repository Structure

- `UnityProject/` - Unity project
- `docs/` - Documentation and screenshots
- `assets/` - External assets and models
- `presentation/` - PPT and review material
- `builds/` - APKs and exported builds
